# Captures d'écran BeautyConnect

Ce dossier est réservé aux captures réelles réalisées depuis l'application locale avec les données de démonstration.

Ajoutez les fichiers aux chemins suivants après vérification manuelle :

- `feed.png` : fil de publications.
- `explore.png` : liste des professionnels.
- `professional-profile.png` : profil et prestations d'un professionnel.
- `booking.png` : parcours de réservation client.
- `professional-bookings.png` : réservation retrouvée côté professionnel.

Ne pas ajouter d'image générée, de maquette ou de capture contenant des données personnelles, secrets ou jetons.
